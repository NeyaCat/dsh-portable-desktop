# DSH Portable Desktop 0.1.2

## 下载选择

- **standard 标准版（推荐）**：使用系统 WebView2；缺少时首次启动可引导安装，下载体积更小。
- **full 完整版**：内置 WebView2 固定运行时，无需另行安装该运行时。

两个版本都包含 Node.js、DSH、Git 和 pnpm。首次安装推荐插件仍需要联网。

## 插件安装体验

- 增加逐插件节点日志，显示解析依赖、下载、复用缓存、安装和校验等步骤。
- 增加单插件进度条和整体进度条；下载大小未知时显示活动进度。
- 固定推荐插件的安装版本，并检查其与当前 DSH 的兼容性。

## 启动修复

- 修复插件等待缺失服务导致页面一直停在“加载 DSH 界面”的问题。
- 检测到阻塞启动的不兼容推荐插件时，暂停该插件、保留配置，并有限重试。
- 修复主题布局容器高度为零时，加载遮罩无法退出的问题。
- 增加前端加载错误和超时诊断，详情记录在 `data/desktop.log`。
- DSH 后台原生遵循便携代理设置；版本与插件下载支持代理和镜像回退。

## 缓存与恢复点

- 正常退出后清理可重建的下载缓存、临时文件、浏览器磁盘缓存，以及已完成事务的临时代码。
- 保留会话、配置、凭据、浏览器登录状态、已安装插件和待切换制品。最小化到托盘不会触发退出清理。
- 新恢复点仅记录 DSH 和插件版本清单，不再复制完整环境。
- 切换版本时保留当前会话和插件配置；相同兼容版本直接复用，需要替换时重新获取。
- 启动验证期间临时保留旧插件代码，健康确认后释放。

## 升级说明

- 建议解压到新的可写目录进行测试，保留原目录及数据。
- 部分推荐插件与内置 DSH 版本不兼容时会被暂停，配置仍保留；不保证全部第三方插件均可启用。
- 旧格式恢复点和旧环境数据暂不自动删除，因此历史磁盘占用不会立即全部释放。
- 内置 DSH：`0.2.0-rc.2`；Node.js：`v24.19.0`。
