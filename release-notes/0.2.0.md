# DSH Portable Desktop 0.2.0

## 下载选择

- **standard 标准版（推荐）**：使用系统 WebView2；缺少时首次启动可引导安装，下载体积更小。
- **full 完整版**：内置 WebView2 固定运行时，无需另行安装该运行时。

两个版本都包含 Node.js、DSH、Git 和 pnpm。首次安装推荐插件仍需要联网。

## 首次启动与必需组件

- 首次启动会查询官方 latest 推荐 DSH 版本；本版内置 `0.2.1-rc.2`，若已有更新则先下载并验证新版本，再安装插件。
- 已有 profile 或显式版本选择保持原样，不会被自动升级或覆盖。
- 插件市场、HTTP 代理、网络配置为必需组件，必须安装并通过校验后才能进入 DSH。
- 推荐插件窗口不再提供跳过入口，也不能通过关闭按钮、Esc 或 Alt+F4 中断；保留「仅安装必需组件」，可选插件仍可按需勾选。
- 已有 profile 缺少必需组件时，只补装必需组件，并保留原插件版本、bundle 选择与 `cordis.patch.yml` 配置。
- 必需组件安装或启动失败时会停止后端并给出明确提示，不再进入组件残缺的界面。

## 安装与更新可靠性

- `required-status` 检查真实依赖、bundle 声明、禁用状态和插件兼容性，不再依赖偏好标记判断是否完成安装。
- 启动完成后再次校验必需组件；必需组件启动失败会直接终止本次启动。
- 版本下载与更新检查支持 `npm_config_registry` 和用户 `.npmrc` 中配置的镜像，并继续沿用便携代理设置。
- 打包脚本默认解析官方 latest DSH 版本，随包携带首次启动模块，并在构建时执行必需组件门禁检查。

## 升级说明

- 建议解压到新的可写目录测试，保留原目录及数据。
- 旧版本的数据、会话和版本选择保持原样；新包启动时会补齐缺失的必需组件。
- 部分第三方插件可能尚未兼容 DSH 0.2.1，安装器会跳过不兼容项并记录原因。
